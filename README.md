# Lista da Casa

PWA colaborativo para compras domésticas.

**Comece por:** `GUIA-DE-INSTALACAO.md`

Arquivos principais:
- `index.html`
- `app.js`
- `styles.css`
- `config.js`
- `manifest.webmanifest`
- `sw.js`
- `supabase-setup.sql`

O app usa Supabase para persistência compartilhada e GitHub Pages para hospedagem estática.
